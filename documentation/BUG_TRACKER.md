# SANTA DASH — Bug Tracker

**Project:** SANTA DASH  
**Status:** Active

---

## 1. Bug Reporting Rules

Every confirmed issue must include:

- Unique identifier.
- Short title.
- Description.
- Reproduction steps.
- Expected behavior.
- Actual behavior.
- Environment.
- Priority.
- Current status.

Do not register speculative issues as confirmed bugs.

## 2. Priority Levels

### Critical

Prevents the game from launching or causes severe data loss.

### High

Breaks an important gameplay feature.

### Medium

Causes noticeable functional problems with available workarounds.

### Low

Minor visual, audio or interface issue.

## 3. Status Definitions

- OPEN
- INVESTIGATING
- IN_PROGRESS
- FIXED
- VERIFIED
- WONT_FIX

## 4. Current Bugs

No confirmed gameplay bugs have been registered.

The project is currently in its foundation and documentation phase.

## 5. Known Limitations

The following items are planned but not implemented:

- Gameplay systems.
- Player movement.
- Track generation.
- Obstacles.
- Collectibles.
- Power-ups.
- Scoring.
- Game progression.
- Monetization integrations.
- Production artistic assets.

These are development tasks, not bugs.
